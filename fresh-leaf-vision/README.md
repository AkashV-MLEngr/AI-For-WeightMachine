# FreshVision Natural UI

Redesign my existing Fruit & Vegetable Detection website with a clean, natural,

premium-looking UI.

IMPORTANT:

Do NOT make it look like a typical AI-generated futuristic dashboard.

Avoid excessive gradients, glowing effects, neon colors, glassmorphism,

robot/AI graphics, and overly rounded UI elements.

DESIGN STYLE:

- Nature-inspired green theme

- Soft natural green background inspired by leaves and fresh vegetables

- Clean white/off-white content sections

- Dark forest green for headings and buttons

- Subtle leaf/plant elements as decoration

- Elegant, minimal and professional

- It should feel like a real product website designed by a human UI designer

- Keep spacing consistent and everything perfectly aligned

- Use a proper centered max-width layout

- All cards should have equal width and consistent height

- Buttons should have consistent size and alignment

TYPOGRAPHY:

Use a stylish slightly slanted/italic font for major headings and the brand name.

The font should look elegant and modern, but NOT like a handwriting font.

Use a clean readable font for normal text.

Use italic/slanted typography selectively for:

- FreshVision AI

- Main hero heading

- Important section headings

Do not make every text italic.

WEBSITE BRAND:

FreshVision AI

MAIN TITLE:

Fruit & Vegetable Detection

SUBTITLE:

Identify fruits and vegetables quickly using intelligent image detection.

MAIN FEATURES:

1. Upload Image

2. Camera Detection

3. Add Training Image

Create three perfectly aligned feature cards in one row on desktop.

Each card should have:

- Simple clean icon

- Title

- Short description

- One consistent green button

DETECTION RESULT:

Create a large clean Detection Result section below the feature cards.

Keep the result area spacious and visually clear.

CAMERA:

Keep the existing camera functionality.

Do not replace or break the existing camera API functionality.

UPLOAD:

Keep the existing image upload and prediction functionality.

Do not change the backend API logic.

TRAINING:

Keep Add Training Image and Train Model functionality working.

IMPORTANT:

The existing FastAPI backend and /predict endpoint must continue working.

Do not rewrite backend functionality unless absolutely necessary.

RESPONSIVE:

Make the website responsive for:

- Desktop

- Laptop

- Tablet

- Mobile

MOBILE:

Cards should stack vertically with proper spacing.

Buttons should remain aligned and easy to tap.

VISUAL DETAILS:

Use subtle shadows, thin borders, clean spacing and natural shapes.

Use small leaf motifs rather than large decorative graphics.

Use fruit/vegetable imagery sparingly.

The overall result should look calm, fresh, elegant and professional.

The final website should look suitable for a college project presentation

and also polished enough to demonstrate as a real application.

Do not add fake statistics, fake reviews, fake users, or unnecessary AI terminology.
